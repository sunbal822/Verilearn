# VeriLearn — AI Powered Smart Viva & Academic Evaluation Platform

## 🚀 Overview

**VeriLearn** is an intelligent AI-powered viva examination platform designed to modernize traditional oral assessments through automation, fairness, security, and real-time evaluation.

The project combines:

- 🤖 AI-generated viva questions
- 🎤 Voice-based answering system
- 🧠 AI answer evaluation and grading
- 🔒 Anti-cheating monitoring
- 👤 Face recognition authentication
- 📄 Automatic document analysis
- 📊 Performance reporting dashboard
- 👨‍🏫 Professor management panel

VeriLearn transforms static and manually conducted viva examinations into a secure, interactive, and scalable digital experience.

# 🧠 Core Idea of the Project

The student uploads academic material such as:

- PDF files
- DOCX documents
- TXT files
- Code files
- Notes
- Assignments

The AI analyzes the uploaded content and automatically generates viva questions categorized by difficulty:

- Easy
- Medium
- Hard

Students answer using:

- Keyboard input
- Voice recognition input

The AI then evaluates the answers intelligently and generates:

- Scores
- Feedback
- Grades
- Performance summaries

Meanwhile, the system continuously monitors suspicious activity using anti-cheat logic.

# 🛠️ Installation Guide

## Clone Repository

```bash
git clone <repository-url>
cd verilearn
```

## Install Dependencies

```bash
npm install
```

## Configure Environment Variables

Create a `.env` file:

```env
VITE_GROQ_API_KEY=your_groq_api_key
```

## Start Development Server

```bash
npm run dev
```

## Build for Production

```bash
npm run build
```
